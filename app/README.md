# Проект «Эхо» — мобильное приложение

Интерактивный мост доверия между детьми 10–12 лет и взрослыми.
PWA на React + TypeScript + Vite: ставится на телефон как обычное приложение
(иконка на домашнем экране, работает офлайн), открывается и просто в браузере.

## Запуск

```bash
npm install --prefix app
```

```bash
npm run dev --prefix app -- --host
```

Флаг `--host` печатает в терминале адрес вида `http://192.168.x.x:5173` —
откройте его на телефоне в той же Wi-Fi сети.

Сборка для публикации:

```bash
npm run build --prefix app
```

Готовые файлы появятся в `app/dist` — их можно выложить на любой статический
хостинг (Vercel, Netlify, GitHub Pages, свой сервер).

### Как поставить на телефон

- **iPhone:** открыть сайт в Safari → «Поделиться» → «На экран "Домой"».
- **Android:** Chrome сам предложит «Установить приложение».

## Что уже сделано

- Выбор роли при первом запуске, смена в настройках.
- Главный экран точно по макету: логотип, пять пунктов меню, нижняя навигация.
- **Я — Подросток:** квест «Новый контакт» (4 финала + разбор), зеркальный режим
  «А что ответит твой взрослый?», три теста из карточки.
- **Я — Взрослый:** квест «День из жизни», режим «Как думаете, что он ответил?»,
  три теста из карточки.
- **Мы вместе:** кооп-квест «48 часов» на одном телефоне по очереди, паузы для
  живого разговора, «Карта решений» в финале.
- **Клуб навигаторов:** сценарий офлайн-встречи на 90 минут для ведущего.
- Словарик сленга: тап по подчёркнутому слову открывает объяснение.
- 20 медалей для обеих ролей, экран прогресса, скрытые медали.
- PWA: манифест, иконки, офлайн-кэш. Прогресс хранится в браузере.

## Психология: почему сделано именно так

**Взрослый не проходит тест про себя.** Тест оценивает человека — защита включается
на первом вопросе, и родитель закрывается. Поэтому в режиме «Я — Взрослый» он
угадывает, что ответил бы его ребёнок. Оценивается догадка, а не личность.
Расхождение взрослый обнаруживает сам — а вывод, сделанный самостоятельно,
не вызывает спора.

**Никакой критики без похвалы.** Каждый результат идёт в порядке: что уже работает →
что можно попробовать. Второй блок — всегда одно небольшое действие, а не список
претензий, и в формулировке «попробуйте», а не «вам нужно».

**Сленг объясняется по запросу.** Родителю не читают лекцию о молодёжном языке:
непонятные слова подчёркнуты, и он сам решает, что открыть. За первое открытое
слово даётся медаль «Переводчик».

**У медалей названия про действие, а не про качество.** «Взял паузу», а не
«Терпеливый родитель»: действие можно повторить, качеством можно только не быть.

**Нет медалей «за неправильно».** Даже тяжёлый финал квеста даёт медаль за опыт:
«Прошёл насквозь — теперь знаешь схему изнутри».

**Скрытые медали.** В списке видно, что открыты не все — незакрытый гештальт
возвращает в приложение лучше любых напоминаний.

**Тесты считают не баллы, а типы.** Шкала «мало/много» всегда читается как оценка
(«у меня низкий балл по доверию»), тип — как описание. Плохих типов в тестах нет,
у каждого расписана сильная сторона.

## Что осталось — и почему без этого пока можно

Всё ниже требует сервера, поэтому в офлайн-версии сделано ближайшее рабочее.

**Связка родитель ↔ ребёнок.** Сейчас в режиме «Как думаете, что он ответил?»
показаны типичные ответы детей этого возраста, а не ответы конкретного ребёнка.
Механика от этого работает, но с реальным ответом станет заметно сильнее.
Нужен код-приглашение и общий профиль пары.

**Синхронизация двух устройств.** Кооп-квест сделан на одном телефоне с передачей
из рук в руки — механика выборов и «Карта решений» те же самые. Для двух экранов
нужен WebSocket из карточки проекта.

**Хранение и приватность.** Прогресс лежит в браузере телефона: переустановил —
потерял. Перед публикацией нужны согласие родителя, политика обработки данных и
решение, что вообще стоит хранить об ответах детей.

**Админ-панель для психологов.** Пока новые сценарии добавляются правкой JSON —
это делается без программиста, но не через интерфейс.

## Структура

```
app/
├── index.html
├── vite.config.ts          настройки сборки и PWA
├── public/
│   ├── icon.svg            знак «Эхо» в вектором виде
│   └── icons/              иконки приложения (192, 512, maskable, apple-touch)
└── src/
    ├── theme.css           дизайн-токены: цвета, тени, скругления
    ├── App.css             стили экранов и компонентов
    ├── App.tsx             сборка приложения и маршруты
    ├── routes.tsx          описание разделов (тексты, иконки, вид)
    ├── data/               JSON-сценарии, словарь сленга
    ├── quest/              движок квестов-переписок
    ├── mirror/             режим «угадай ответ ребёнка»
    ├── glossary/           подсветка сленга и всплывающие объяснения
    ├── progress/           медали и хранение прогресса
    ├── components/         логотип, иконки, пункт меню, таб-бар
    └── screens/            главный экран, раздел, медали, настройки
```

Все цвета, тени и скругления заданы переменными в `src/theme.css` —
чтобы поменять фирменный цвет, достаточно править только этот файл.

## Что можно править без программиста

| Файл | Что в нём |
|---|---|
| `src/data/new-contact.json` | квест подростка: переписка, выборы, финалы, разбор |
| `src/data/day-in-life.json` | квест взрослого: день от лица ребёнка |
| `src/data/mirror-adult.json` | ситуации для взрослого, ответы детей, цитаты, итоги |
| `src/data/mirror-teen.json` | то же зеркально: подросток угадывает взрослого |
| `src/data/tests-teen.json` | три теста подростка: вопросы, типы, тексты результатов |
| `src/data/tests-adult.json` | три теста взрослого |
| `src/data/coop-48.json` | кооп-квест: сцены, выборы обеих сторон, паузы |
| `src/data/glossary.json` | словарь сленга: слово, объяснение, что это значит для взрослого |
| `src/progress/badges.ts` | медали: название, за что, сильная сторона, что попробовать |
| `src/screens/ClubScreen.tsx` | программа офлайн-встречи |
| `src/routes.tsx` | состав разделов на главном экране |

В `badges.ts` в начале файла записаны правила формулировок — их стоит прочитать
перед тем, как добавлять новые медали.
