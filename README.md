# Проект «Эхо»

Интерактивный мост доверия между детьми 10–12 лет и взрослыми.
Мобильное приложение (PWA) с тремя режимами и офлайн-программой.

Автор: Валеева Лиана Николаевна.

**Приложение — в папке [`app/`](app/). Там же README с описанием, психологией
решений и инструкцией по запуску.**

## Публикация

Сайт собирается и выкладывается автоматически при каждом пуше в `main` —
см. [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
