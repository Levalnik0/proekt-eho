# Презентация проекта

Готовый файл — `Проект_Эхо_презентация.pptx` в корне проекта.
Здесь лежит то, из чего он собирается, чтобы можно было пересобрать
или поправить, не начиная заново.

| Файл | Что это |
|---|---|
| `build.js` | сборка презентации: все тексты слайдов и вёрстка |
| `cover.py` | фон титульного слайда: круги, расходящиеся из телефона |
| `preview.py` | проверка готового файла: рисует его в HTML и ищет переполнение текста |
| `map.html` | схема «Карты решений», из неё сделан `shots/map.png` |
| `shots/` | экраны приложения, фон титула и QR-код |

## Как пересобрать

```bash
cd presentation && npm install pptxgenjs && node build.js
```

Файл сразу кладётся в корень проекта, переносить ничего не нужно.

Фон титульного слайда пересобирается отдельно, если поменялась палитра:

```bash
.venv/bin/python cover.py
```

## Как обновить QR-код

`shots/qr.png` сделан из `qrcode.pdf` в корне проекта. Если код поменяется,
повторите два шага: перевести в картинку и обрезать до квадрата с полями.

```bash
sips -s format png -Z 1600 ../qrcode.pdf --out shots/qr.png
```

```bash
.venv/bin/python -c "
from PIL import Image
im = Image.open('shots/qr.png')
white = Image.new('RGB', im.size, (255, 255, 255))
white.paste(im, mask=im.split()[3])
box = white.convert('L').point(lambda p: 255 if p < 128 else 0).getbbox()
side = max(box[2] - box[0], box[3] - box[1])
pad = int(side * 0.09)
cx, cy = (box[0] + box[2]) // 2, (box[1] + box[3]) // 2
half = side // 2 + pad
white.crop((cx-half, cy-half, cx+half, cy+half)).resize((900, 900), Image.LANCZOS).save('shots/qr.png')
"
```

Фон в PDF прозрачный, поэтому его сначала кладут на белое: иначе пустое
место станет чёрным и код не прочитается.

## Как проверить, что ничего не разъехалось

```bash
python3 -m venv .venv && .venv/bin/pip install python-pptx && .venv/bin/python preview.py ../Проект_Эхо_презентация.pptx
```

Скрипт создаст `preview.html`. Откройте его в браузере: блоки, где текст
не поместился, обведены красным, и они же перечислены в `window.overflows`
в консоли.

Два флага помогают разглядывать мелочи:

```bash
.venv/bin/python preview.py ../Проект_Эхо_презентация.pptx --only=7 --scale=2
```

`--only` оставляет один слайд, `--scale` рисует его крупнее.

Чего превью не умеет: шрифтов Cambria и Calibri в macOS нет, вместо них
подставляются Times и Arial. Они шире оригиналов, поэтому если текст влез
здесь, в PowerPoint он влезет тем более, а вот ширина строки до пикселя
не совпадёт.

## Разметка слайдов

Вся вёрстка держится на трёх числах в начале `build.js`: `TOP` — где
начинается содержимое под заголовком, `BOTTOM` — докуда доходит, `M` —
поля. Если двигать блоки мимо них, слайды разъедутся между собой.

Заголовок помещается в одну строку примерно до тридцати знаков. Длиннее —
переносится на вторую и налезает на содержимое; проверка это ловит.

## Как обновить экраны приложения

Экраны сняты браузером с запущенного приложения — каждый в рамке телефона,
которая появляется на широком экране. Порядок такой: запустить `npm run dev`
в папке `app`, открыть нужный экран в браузере шириной около 1000 пикселей
и снять область с телефоном.

Готовые снимки: главная, квест-переписка, проверка сообщения, медали,
экран «Здесь проверяют не вас», программа офлайн-встречи.
